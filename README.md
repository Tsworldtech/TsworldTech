I run TSWORLDTECH, where I build software products and take on client work as an agency. Most of what I do lives at the intersection of engineering and product thinking, shipping things that work reliably in the real world, not just in a demo.

I decided to build **Flux** as the infrastructure layer that controls how web applications speak to their server, a system designed to work with every database and every realtime state manager, and in the long run, framework-agnostic for frontends. It cuts out the excess in how apps communicate with the backend, which translates directly into lower server costs and faster, more resilient applications.

We are going to make a difference in how applications are built.
